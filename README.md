## 📋 Описание

EVM Wallet Dashboard - это Python-скрипт для массового анализа балансов криптовалютных кошельков в различных EVM-совместимых сетях. Инструмент собирает информацию о токенах и их стоимости, создавая удобный HTML-дашборд с возможностью сортировки.

## 🌐 Поддерживаемые сети

- **Ethereum (ETH)** - Основная сеть Ethereum
- **Arbitrum (ARB)** - L2 решение для Ethereum
- **Avalanche (AVAX)** - Быстрая и масштабируемая блокчейн-платформа
- **Base** - L2 сеть от Coinbase
- **Binance Smart Chain (BSC)** - Сеть Binance
- **zkSync Era (ERA)** - ZK-rollup решение
- **Fantom (FTM)** - Высокопроизводительная сеть
- **Polygon (MATIC)** - Решение масштабирования Ethereum
- **Arbitrum Nova (NOVA)** - Оптимизированная версия Arbitrum
- **Optimism (OP)** - Оптимистичный rollup
- **Sonic** - Быстрая EVM-сеть
- **Zora** - Сеть для NFT и креативов

## ✨ Возможности

- 📊 **Массовый анализ** кошельков в 12 EVM-сетях
- 💰 **Автоматический расчет** стоимости токенов в USD
- 🔄 **Поддержка прокси** для обхода лимитов API
- 📱 **Красивый веб-дашборд** с сортировкой по стоимости
- ⚡ **Асинхронная обработка** для высокой скорости
- 🛡️ **Обработка ошибок** и повторные попытки
- 📈 **Сортировка от большего к меньшему** балансу

## 🚀 Быстрый старт

### Вариант 1: Автоматическая установка (рекомендуется)

**Windows:**
```bash
# Скачайте проект и запустите
INSTALL.bat
START.bat
```

**Linux/macOS:**
```bash
# Скачайте проект и запустите
chmod +x install.sh start.sh
./install.sh
./start.sh
```

### Вариант 2: Ручная установка

1. **Клонирование репозитория**
```bash
git clone <repository-url>
cd evm_dashboard_public
```

2. **Установка зависимостей**
```bash
pip install -r requirements.txt
```

3. **Настройка файлов**

**proxy.txt** - добавьте прокси (по одному на строку):
```
login:pass@ip:port
user123:pass456@192.168.1.1:8080
```

**addr.txt** - добавьте адреса кошельков (по одному на строку):
```
0x742d35Cc6479C53C50c6f6ed6F9e0bE85Dd6e4b9
0x8888888888888888888888888888888888888888
```

4. **Запуск**
```bash
python main.py
```

## 🔧 Конфигурация

### Прокси серверы
Для обхода лимитов API рекомендуется использовать ротацию прокси. Поддерживается формат:
```
login:pass@ip:port
```

**Рекомендуемые провайдеры:**
- [Proxyshard](https://proxyshard.com?ref=coun1er) (резидентские прокси с оплатой за трафик) ([без реф](https://proxyshard.com))
- Другие качественные провайдеры прокси

### Адреса кошельков
Добавьте EVM-совместимые адреса в файл `addr.txt`. Поддерживаются адреса формата:
```
0x742d35Cc6479C53C50c6f6ed6F9e0bE85Dd6e4b9
```

## 📊 Результаты

После завершения работы скрипт создает файл `wallets_dashboard.html` с:

- 📈 **Таблицей балансов** всех найденных токенов
- 💵 **Стоимостью в USD** для каждого токена
- 🔄 **Сортировкой** от большего к меньшему балансу
- 🎨 **Красивым интерфейсом** для удобного анализа
- 🔍 **Детальной информацией** по каждому кошельку

Просто откройте файл в любом браузере и наслаждайтесь результатами!

## ⚙️ Технические детали

- **Язык:** Python 3.7+
- **Асинхронность:** asyncio для параллельной обработки
- **HTTP клиент:** curl-cffi с имитацией браузера Chrome
- **Шаблонизатор:** Jinja2 для генерации HTML
